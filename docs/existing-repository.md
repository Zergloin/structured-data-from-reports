# Материалы предыдущих этапов

Репозиторий: https://github.com/Zergloin/structured-data-from-reports

Исходная main содержит коммит 45f3b445b1e7e69714c7d945bde781ceb535d027
с моделями системного контекста и контейнеров. Файлы main.puml и diagrams/
сохраняются на своих местах. Они относятся к первоначальной версии ЛР1.

Актуальные модели общего проекта находятся в src/, прототипы - в prototype/.
В ЛР1-ЛР4 модели проверяются локально. В начале ЛР5 тимлид подключает CI.
После этого CI проверяет входы ci/catalog.json, подключения, контракты и тесты.
Файлы main.puml, diagrams/ и backend/ не являются входами этого каталога.
Поэтому успешный CI не подтверждает рендер этих исторических копий.

Backend ЛР2 первоначально предложен в PR #1:
https://github.com/Zergloin/structured-data-from-reports/pull/1
Исходный коммит: cd9e3cddd66d9c0a68f6288bc4e8c40bae703d9a.
Он включается в историю feature/backend обычным merge без переписывания.
В backend/ сохраняются исходные компонентные схемы, contracts.md и изображения.
Два служебных файла .DS_Store исключаются из результата слияния.

После переноса автор backend обновляет модели в общей структуре src/.
Итоговый PR backend в main заменяет прежний PR #1 и содержит ссылку на него.
Это перенос ранее выполненной части, а не новая разработка ЛР2 с нуля.
