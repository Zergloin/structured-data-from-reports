# Проверка своей части: analyst

Проверить создание, проверку и публикацию схемы. Опубликованная версия остается неизменной и используется заданиями по точному идентификатору.

Перед pull request выполнить:

```sh
python ci/build.py --mode auto --lint-only
python ci/build.py --mode auto
```

Приложить ссылку на артефакт architecture и указать измененные src-файлы. Проверить изображение вручную: обрезанные подписи и пересечения не выявляются синтаксическим анализом. Запрашивать review у тимлида; автор PR не заменяет независимого рецензента.

PR в main открывается в ЛР5 после работы над ЛР1-ЛР4 в одной feature-ветке. В review указать режим частичной или полной сборки. Для итогового PR тимлида требуется полная сборка.
