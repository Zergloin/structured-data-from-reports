# Проверка части backend

Backend передает изменения в ветке feature/backend. Создание pull request,
слияния и проверку CI выполняет тимлид.

При проверке нужно рассмотреть семь компонентов worker, обращение
extractor_comp к llm и сохранение результата через worker_repository_comp.
Успешное извлечение не означает принятие записи экспертом.

Контракт ci/contracts/backend.json задает обязательные элементы и связи,
а ci/contributions/backend.json перечисляет файлы этой части проекта.
Эти описания используются общей проверкой после подключения CI тимлидом.

Тимлид проверяет результат сборки и изображения: обрезанные подписи
и пересечения линий не выявляются синтаксическим анализом. Результат
проверки подтверждается ссылкой на фактический запуск и его артефакты.
