# Работа с моделями до общей интеграции

Участники работают в feature/teamlead, feature/backend, feature/analyst,
feature/techdoc и feature/devops. Изменения ЛР1-ЛР4 последовательно
фиксируются в собственной ветке и отправляются в основной репозиторий.
Ранее опубликованные коммиты сохраняются, авторы и даты не подменяются.

Локальные модели проверяются в PlantUML. До начала ЛР5 автоматической
проверки GitHub Actions нет. После push не требуется ожидать ее статуса.

В начале ЛР5 тимлид отдельно подключает сборщик и workflow, затем
команда открывает итоговые PR с независимым review и проверкой CI.
Порядок приема частей: backend, analyst, techdoc, devops, teamlead.
