# Локальный просмотр

Нужны Docker с Compose и расширение PlantUML для VS Code. Из корня репозитория выполнить `docker compose up -d`. Сервер доступен только на 127.0.0.1:18080. Настройки расширения находятся в .vscode. Для многомодульной модели корнем поиска include служит /workspace/src; если клиент передает неполный фрагмент, для контрольного результата использовать `python ci/build.py --mode auto`. Сервер нужен для предварительного просмотра; приемочный рендер выполняется закрепленным JAR из toolchain.lock.json. Версии серверного и приемочного рендера могут различаться.

После работы выполнить `docker compose down`. Не переключать профиль на LEGACY. В CI Docker-сервер не нужен: Java и Graphviz рисуют схемы непосредственно в runner.

Для проверки include независимо от поведения расширения выполнить `python ci/preview.py src/context/context.puml`. Скрипт передает серверу путь к смонтированному исходнику и сохраняет SVG в .build/preview. Эта команда использована для проверки контейнерного предпросмотра.
