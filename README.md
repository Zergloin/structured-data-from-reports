# C4-диаграммы: ИС структурированных данных на основе текстовых отчётов

Исходники архитектурных моделей C4 (уровень 1 - системный контекст, уровень 2 - контейнеры) для проекта «Разработка информационной системы формирования, верификации и управления структурированными данными на основе текстовых отчётов».

## Состав

| Файл | Диаграмма |
|---|---|
| `main.puml` | Мастер-диаграмма системного контекста (5 ролей, 3 внешние системы, 8 связей) |
| `diagrams/context.puml` | То же общее представление (совместная копия) |
| `diagrams/containers.puml` | Общая диаграмма контейнеров (8 контейнеров, 18 связей) |
| `diagrams/local_containers_*.puml` | Пять локальных представлений участников: схемы, извлечение, верификация, реестр, маршрутизация заданий |
| `diagrams/vendor/` | C4-PlantUML 2.12.0 (MIT) - библиотека, нужная для рендера |

Пять локальных моделей при объединении в точности дают общую диаграмму контейнеров: общие ID, подписи и протоколы согласованы.
