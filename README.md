# ИС структурированных данных из текстовых отчетов

Тема: Разработка информационной системы формирования, верификации и управления структурированными данными на основе текстовых отчетов.

Общая основа содержит определения системы, пользователей, контейнеров,
стиль src/style.puml и локальную библиотеку C4-PlantUML 2.12.0 с лицензией.
Участники добавляют собственные модели в src/context, src/containers,
src/components, src/code, src/landscape, src/dynamic и src/deployment.
Прототипы ЛР3 находятся в prototype.

ЛР1-ЛР4 выполняются в пяти рабочих feature-ветках. Проверка моделей
выполняется локально через PlantUML или предпросмотр VS Code.
Перед коммитом проверяются исходники и полученные изображения.

Автоматическая проверка GitHub Actions подключается тимлидом в ЛР5.
До этого этапа каталог ci и workflow в общей основе отсутствуют.
Порядок командной работы описан в docs/github-setup.md.

## Первоначальные материалы

Корневой main.puml и diagrams/ сохраняют первоначальную версию ЛР1.
Каталог backend/ содержит предыдущую индивидуальную версию ЛР2 после ее
переноса из PR #1. Вход общего контекста - src/context/context.puml.
После интеграции в ЛР5 общая контейнерная модель находится в src/main.puml.
Порядок сохранения прежних материалов описан в docs/existing-repository.md.
